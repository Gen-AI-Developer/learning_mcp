# Learning MCP

This repository contains resources, tools, and examples for learning and implementing MCP (Model-Checking Protocols). Below is a detailed description of the files and directories in this repository.

---

## Directory and File Descriptions

### 01_learning_client
This directory contains Python scripts for learning and experimenting with MCP client-side operations.

- **00_Abit_Ultra_basic.py**: A very basic example of an MCP client.
- **00_basic_with_context_manager.py**: Demonstrates the use of a context manager in an MCP client.
- **01_connection_open_close_with_asynccontextmanager.py**: Shows how to manage client connections using `asynccontextmanager`.
- **02_client_session.py**: Explores client sessions in MCP.
- **03_nested_client_connection_sessions.py**: Demonstrates nested client connections and sessions.
- **04_AsyncExitStack_in_connection_client.py**: Uses `AsyncExitStack` for managing client connections.
- **05_Clearnup_in_AsyncExitStack_in_connection_client.py**: Focuses on cleanup operations in `AsyncExitStack` for clients.
- **06_00_client_.py**: A lightweight client implementation.
- **06_01_client_lite.py**: Another minimalistic client example.
- **07_mcp_client.py**: A more advanced MCP client implementation.
- **08_client.py**: A general-purpose MCP client script.
- **data.txt**: Sample data used by the client scripts.
- **output.txt**: Output generated by the client scripts.
- **README.md**: Documentation for the `01_learning_client` directory.
